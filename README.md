# Git Practice Repository

This repository contains notes and examples for learning and practicing Git commands and workflows.

## Contents

- `git_practice.txt` - a collection of basic Git commands, branch operations, merge/rebase workflows, and common Git usage patterns.
- `Git_cheat_sheet.jpg` - a visual cheat sheet for Git commands.

## Purpose

Use this repository to review and practice Git essentials such as:

- initializing repositories
- staging and committing changes
- creating and switching branches
- pushing branches to remote
- fetching, merging, and rebasing
- resolving conflicts and reverting commits

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/nhanguyenht/git_practice.git
   ```
2. Open the repository folder.
3. Review `git_practice.txt` for commands and examples.
4. Practice commands locally and push branches to remote as needed.

## Notes

This repo is intended as a personal Git reference and learning workspace.
